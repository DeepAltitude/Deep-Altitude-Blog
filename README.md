# Deep Altitude

A notebook about physical practice, languages and thinking.

**Rašymas išgrynina mąstymą.**

Live at https://deepaltitude.com. Built with Astro; GitHub is the source of truth and the existing Cloudflare integration deploys the main branch.

## Publish a note

Open https://app.pagescms.org/ → **DeepAltitude / Deep-Altitude-Blog → main → Articles → Add an entry (the + button on a phone)**. Fill in the title, category, language and date, write, and save. Images can be uploaded directly from your phone or laptop. Saving publishes through the existing build.

See [publishing and development notes](notebook/README.md) for image formats, editing existing articles, languages and build commands. [Release validation](notebook/VALIDATION.md) records the checks made for this version.
